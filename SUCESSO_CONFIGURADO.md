```cmd
REM Instalar no celular/emulador

REM Ver logs
adb logcat

REM Usando npm scripts também funciona
```

## 🆘 Encontrou Erro?

Não se preocupe! Siga esses passos:

1. **Ler a Solução:** Procure em `TROUBLESHOOTING.md`
2. **Verificar Ambiente:** Execute `check-environment.bat`
3. **Limpar Cache:** `cd android && gradlew.bat clean && cd ..`
4. **Reinstalar Deps:** `npm install`
5. **Tentar Novamente:** `build-apk.bat`

Se ainda não funcionar, consulte `TROUBLESHOOTING.md` ou veja logs com:
```cmd
adb logcat | findstr ERROR
```

